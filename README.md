# 📊 Zudio Retail Sales Dashboard – Excel

## 📌 Project Overview

This project presents an interactive **Zudio Retail Sales Dashboard** developed in Microsoft Excel to analyze retail sales performance and identify key business trends.

The dashboard transforms raw retail transaction data into meaningful visual insights using **PivotTables, PivotCharts, KPI Cards, Slicers, and Map Charts**.

The objective of this project is to understand sales performance across products, categories, states, store types, customers, and time periods.

---

## 🎯 Business Objectives

The dashboard was designed to answer key business questions such as:

- What are the total sales and profit?
- How many units were sold?
- How many orders and customers were recorded?
- Which states generate the highest sales?
- Which categories perform the best?
- Which clothing types have the highest sales?
- How does sales performance change month by month?
- How does performance differ between owned and rented stores?
- Which regions require further business attention?

---
